# VEYDRIS

**Computer vision · Video analysis · Tracking · Research software**  
**Project context:** Nurowerx · November 2026

VEYDRIS is a locally implemented video-analysis prototype featuring real object detection/tracking on uploaded footage, video replay, annotations, result exports, authentication, and a separate **synthetic map demonstration**.

| Automated tests | **36 passed** |

**Verification boundary:** These claims come from the project's local completion summary, not from an independent audit of the executable or full source code. No publicly measured model accuracy or tracking metrics are available here.

**Not yet implemented or verified:** Live drone connections and real geolocation remain future development. Docker/PostGIS configuration is present in the local archive, but has **not been runtime-tested**. The synthetic map does not indicate true tracked locations.

**Publication:** The full application, model, and sample package still reside locally; there is **no public source repository or online demonstration** identified by this document. Local authentication credentials and private Windows paths are intentionally omitted.
